# 🚚 Handle With Care
### — 던지지 마시오 —

**배송은 팀워크, 사고는 우정**

> **"당신과 친구들은 처참할 정도로 서툰 이삿짐 배달부입니다. 깨지기 쉬운 초대형 화물을
> 아수라장 같은 코스로 직접 날라야 하죠 — 떨어뜨리고, 부수고, 비명 지르는 순간마다
> 월급이 통장에서 증발합니다."**

**친구 2~4명이 함께 즐기는 3D 협동 파티 게임** 입니다.
같이 무거운 짐을 들고, 좁은 길을 지나고, 서로 탓하며 웃다 보면 어느새 한 판이 끝나 있어요.
클립으로 남기기 딱 좋은, 스트리밍하기 좋은, 그리고 무엇보다 **친구랑 하면 훨씬 재밌는** 게임을 목표로 만들었습니다.

---

## 🎮 어떤 게임인가요?

여러분은 악명 높은 배송 회사 **캡숑빨라 CO.** 의 신입 배달부입니다.
할 일은 단순해요. **짐을 집어서, 트럭까지 무사히 옮기고, 마감 시간 안에 배달하기.**

문제는… 그게 절대 단순하지 않다는 거죠.

- 짐은 **혼자 못 드는** 크기라 친구와 **양쪽에서 같이** 들어야 하고,
- 화물에는 **퓨즈(도화선)** 가 달려 있어서 **험하게 다룰수록 점점 빨갛게 달아오르며 폭발**에 가까워지고,
- 바닥은 미끄럽고, 길은 좁고, 옆에서 친구는 자꾸 부딪히고,
- 매일 **오늘만의 변수(데일리 모디파이어)** 가 판을 뒤집어 놓습니다.

한 판은 약 **3분**. 마감 시간이 다가올수록 서두르게 되고, 서두를수록 사고가 나고,
사고가 날수록… 더 웃깁니다.

---

## 🔥 핵심 재미

### 💣 화물이 곧 시한폭탄
모든 화물에는 **퓨즈**가 있습니다. 가만히 둬도 서서히 타들어가고, **부딪히거나 떨어뜨릴 때마다 확 줄어듭니다.**
퓨즈가 짧아질수록 화물은 **더 빨갛게, 더 빠르게 깜빡이고** — 0이 되는 순간 **폭발**합니다.
근처의 다른 폭탄까지 **연쇄 폭발**로 터지고, 화면이 흔들리며, 그 판은 그대로 끝.
👉 **트럭에 무사히 실으면 해체 완료.** "친구 품 안에서 터지기 전에, 살살 옮기세요."

### 🤝 둘이서 함께 나르기
큰 짐은 **두 사람이 양쪽 손잡이를 잡아야** 제대로 들립니다.
혼자 무리하게 들면? 비틀비틀 질질 끌리다가 결국 사달이 나죠. (그리고 그게 웃겨요.)
호흡을 맞춰 걷고, "왼쪽!", "잠깐 멈춰!" 를 외치는 그 순간이 이 게임의 진짜 재미입니다.

### 🎙️ 거리 기반 보이스 챗
가까이 있는 친구의 목소리는 크게, 멀어지면 작게 들리는 **3D 근접 음성 채팅**을 내장했습니다.
그리고 이 장르의 국룰 — **폭발에 휘말려 아웃되면 목소리도 사라집니다.** (제일 웃긴 포인트)

### 📅 매일 바뀌는 오늘의 변수
날짜가 넘어갈 때마다 판을 통째로 바꾸는 **데일리 모디파이어**가 걸립니다. (1일차는 항상 평온한 날)

| 모디파이어 | 효과 |
|---|---|
| 🕐 **러시아워** | 퓨즈가 훨씬 빨리 탐 — 서둘러! |
| 📦 **더블 로드** | 폭탄이 하나 더 |
| ⚠️ **위험 수당** | 퓨즈는 짧아지지만 보수는 두둑하게 |
| 🧨 **철거의 날** | 폭발 반경·위력 대폭 상승 (한 방이 커진다) |
| 🌿 **여유로운 길** | 퓨즈는 길지만 보수는 짜게 (평화롭고 값싼 날) |
| 💰 **페이데이** | 보수 2배 + 폭탄 하나 추가 (하이 리스크, 하이 리턴) |
| 🧈 **미끌미끌한 날** | 화물이 손에서 미끄러지고 바닥을 주르륵 |
| 🏀 **고무의 날** | 떨어뜨린 화물이 통통 튀어 다님 |

### 🎲 라운드마다 다른 화물
같은 판 안에서도 화물마다 성격이 다릅니다.
**일반 / 불안정(짧은 퓨즈·한 손 들기) / 미끌(잘 미끄러짐) / 무거움(반드시 둘이서·더 큼)** —
색으로 미리 알려주니 보고 대비하세요. 날이 갈수록 험한 화물이 더 자주 나옵니다.

### 🛒 로그라이트 증강 상점
라운드 사이, 그동안 번 돈으로 **증강**을 삽니다. 단, 모든 증강엔 **트레이드오프**가 있어요.
12종의 증강을 조합해 우리 팀만의 스타일을 만들어 보세요!

### 🎁 아이템 & 배달 콤보
- 배달 중 맵에 떨어지는 **가챠 캡슐**을 열면 **부스터 신발, 동료 스태미나 깃발, 응원 나팔, 에너지 드링크** 같은 아이템이!
- 짧은 시간 안에 연속으로 배달하면 **콤보**가 쌓여 보수가 최대 **3배**까지 뻥튀기됩니다.

### ✨ 그 외
- ⚡ **대시(전력질주)** — 스태미나 게이지를 관리하며 위기 탈출
- 📍 **핑 & 이모트 휠** — 목소리 대신 빠르게 신호 보내기
- 🏆 **MVP·스코어보드·런 등급** — 판이 끝나면 누가 사고뭉치였는지 정산
- 📸 **결과 공유용 캡처** — 클립·스크린샷으로 남기기 좋게

## 🕹️ 플레이 방법

- **인원**: 2~4명 협동 (호스트 1명이 방을 열고 친구가 참가)
- **한 판**: 브리핑 → 하울링(운반) 약 3분 → 정산, 날이 쌓일수록 난이도 상승
- **기본 조작**: 이동 / 점프 / **집기(잡기)** / 던지기 / 대시 / 핑·이모트
- **연결**: 같은 네트워크에서 빠른 매칭, 또는 IP 직접 접속
- **언어**: 🇰🇷 한국어 · 🇺🇸 English · 🇯🇵 日本語 · 🇨🇳 中文 지원

## 🛠️ 기술 스택

| 분야 | 사용 기술 |
|---|---|
| **엔진** | Unity 6.5 (**6000.5.7f1** — 이 버전으로 열어야 합니다) |
| **멀티플레이어** | Netcode for GameObjects 2.13 — 서버 권위(server-authoritative) 협동 네트워킹 |
| **음성 채팅** | NGO 기반 **커스텀 3D 근접 보이스 챗** (16kHz PCM, VAD 게이트, 거리 감쇠) |
| **렌더링** | Universal Render Pipeline (URP) 17.5 |
| **입력** | Unity Input System 1.20 (키보드·게임패드·마우스 룩) |
| **UI** | uGUI 2.5 |
| **물리** | Unity Physics — PD 힘 제어 기반 협동 운반, 런타임 표면 재질(마찰/반발) |
| **매치메이킹** | LAN UDP 브로드캐스트 빠른 매칭 + IP 직접 접속, **Steam** 로비/초대(옵션) |
| **테스트** | Unity Test Framework — 순수 게임 로직 EditMode 유닛 테스트 |
| **아트/사운드** | **CC0** 에셋 — Kenney(캐릭터·가구·음식·차량 킷·효과음) + PolyHaven·AmbientCG(PBR 텍스처·HDRI). 저장소에 포함되어 별도 다운로드가 필요 없습니다 |

### 설계 하이라이트
- **결정론적 규칙**: 데일리 모디파이어·화물 아키타입·콤보 계산 등 핵심 규칙은 UnityEngine에 의존하지 않는 **순수 로직**으로 분리 — 별도 네트워크 동기화 없이 서버·클라이언트가 같은 결과를 계산하고, 단위 테스트로 검증됩니다.
- **서버 권위 물리**: 화물·폭발·연쇄 반응은 서버가 시뮬레이션하고 그 결과가 자연스럽게 복제되어, 추가 RPC 없이도 모두가 같은 장면을 봅니다.
- **오너 로컬 반응성**: 대시·폭발 넉백 등 조작감이 중요한 요소는 소유 클라이언트가 즉시 반응하고 NetworkTransform이 결과만 복제 — 입력 지연을 최소화했습니다.
